# License decision notes

Choose licenses before public repository release. This file separates local project outputs from upstream data products so that the archive does not imply rights the project does not hold.

## Project-generated materials

These items can usually be licensed by the manuscript author group, subject to institutional requirements:

- Custom scripts under `scripts/`
- Figure source CSV files generated by the workflow
- Manuscript support documents under `manuscript/`
- Generated figures, subject to journal and author policies
- Compact reproducibility package metadata

Possible choices:

- Code: MIT, BSD-3-Clause, Apache-2.0, or another institution-approved open-source license.
- Processed tables and documentation: CC BY 4.0 or another repository-approved data/documentation license.

## Upstream data products

The project does not relicense upstream data products. Check and follow the original terms for:

- GSSR
- COAST-RP
- DeltaDTM
- ERA5 / Open-Meteo access route

If raw upstream subsets are included in any archive, document their source, license/terms, and reason for inclusion. Prefer citing upstream repositories rather than duplicating large raw datasets.

## Recommended release wording

"This repository contains project-generated scripts, processed source tables, figures, and manuscript-support files. Upstream data products remain governed by their original licenses and terms of use and should be cited through their original repositories."

## Before public release

- Confirm license choice with all authors and institutional requirements.
- Add a root `LICENSE` file if the package is released publicly.
- Add license information to the repository README.
- Confirm that generated source tables do not violate upstream redistribution terms.
- Confirm journal policy for sharing accepted manuscript figures.
