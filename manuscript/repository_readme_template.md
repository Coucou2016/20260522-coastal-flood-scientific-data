# Repository README template

Use this template for the public archive that will host the processed source data, code and compact manuscript package.

## Title

Process-terrain coastal flood susceptibility screening using open water-level, meteorological and DeltaDTM terrain data

## Description

This repository contains the processed source tables, figure-generation scripts, audit scripts and compact manuscript package for a process-terrain coastal flood screening study. The workflow combines public GSSR surge-residual reconstructions, COAST-RP storm-tide return levels, Open-Meteo ERA5-derived meteorological variables and DeltaDTM coastal terrain.

The study is a reproducible screening analysis. It does not estimate observed flood extent, hydrodynamic inundation, flood risk, exposure, vulnerability, damages or defence performance.

## Main contents

- `publication_package.zip`: compact manuscript package generated by `scripts/finalize_cee_publication_package.py`.
- `publication_package/`: unpacked copy of the compact package.
- `data/figure_source/`: CSV source data for the main figures and manuscript tables.
- `figures/main/`: main figures as PNG and PDF.
- `scripts/`: key processing, figure-generation and audit scripts.
- `requirements.txt` and `environment.yml`: environment specifications.
- `manuscript/publication_readiness_report.md`: finalization and audit report.

## Upstream data

The large upstream raw data products are public and should be cited from their original repositories rather than duplicated unless license and archive-size constraints allow:

- GSSR: https://doi.org/10.6084/m9.figshare.c.5124878
- COAST-RP: https://doi.org/10.4121/13392314
- DeltaDTM: see Pronk et al., Scientific Data, https://doi.org/10.1038/s41597-024-03091-9
- ERA5 / Open-Meteo historical weather access: cite ERA5 and document Open-Meteo access route.

## Reproduce the final package

From the project root:

```powershell
python scripts\finalize_cee_publication_package.py
```

or on Windows:

```cmd
scripts\run_finalization.cmd
```

Successful execution should create `publication_package/`, `publication_package.zip` and `manuscript/publication_readiness_report.md`.

## Quality assurance

The finalization workflow runs:

- raw-download verification,
- quality-audit diagnostics,
- figure rebuilding,
- standalone HTML rebuilding,
- script compilation checks,
- publication-readiness checks,
- package manifest generation,
- ZIP archive verification.

The package should not be reused as a final release unless `PUBLICATION READINESS AUDIT: PASS` is recorded in `manuscript/publication_readiness_report.md`.
