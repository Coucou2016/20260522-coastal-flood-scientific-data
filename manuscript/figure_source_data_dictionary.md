# Figure source-data dictionary

This dictionary documents the source tables used to draw the manuscript figures and tables. It should be kept with the manuscript package so that reviewers can trace plotted values back to reproducible tabular outputs.

## General conventions

- Distances are in kilometres unless otherwise stated.
- Elevations and water-level indicators are in metres.
- Percentages are reported as fractions of the stated analysis mask, not as fractions of total administrative or exposed population area.
- `D10_m` is a diagnostic product-definition difference: `COAST-RP 10-year storm tide - GSSR 10-year surge residual`.
- DeltaDTM terrain sensitivity is a static terrain screen. It is not a dynamic flood forecast.

## `Fig1_station_metadata.csv`

Station-level metadata for the eight screening sites.

| Column | Meaning |
|---|---|
| `station_id` | Project station identifier. |
| `station` / `label` | Full or shortened site label used in figures. |
| `country` | Country or territory label from the station configuration. |
| `lat`, `lon` | Tide-gauge coordinates. |
| `terrain_screen` | Whether the site has a DeltaDTM terrain-screening window in the current implementation. |

## `Fig2_water_level_divergence.csv`

Source table for Figure 2.

| Column | Meaning |
|---|---|
| `station_id` | Project station identifier. |
| `full_label` | Display label. |
| `region` | `Europe` for the five terrain-screening sites, `Comparison` for the remaining diagnostic sites. |
| `gssr_rp10_m` | Empirical 10-year indicator from GSSR reconstructed surge residuals. |
| `coast_rp_rp10_m` | Matched COAST-RP 10-year storm-tide return level. |
| `D10_m` | `coast_rp_rp10_m - gssr_rp10_m`. |
| `match_dist_km` | Distance between tide-gauge coordinate and matched COAST-RP coastal point. |

## `Fig3_driver_correlations.csv`

Source table for Figure 3.

| Column | Meaning |
|---|---|
| `station_id` | Project station identifier. |
| `label` | Short site label. |
| `n_days` | Number of matched daily GSSR/Open-Meteo records used. |
| `pressure` | Spearman rank correlation between daily GSSR surge and daily minimum mean sea-level pressure. |
| `wind` | Spearman rank correlation between daily GSSR surge and daily maximum wind speed. |
| `precipitation` | Spearman rank correlation between daily GSSR surge and daily precipitation. |

## `Fig4_connected_terrain_sensitivity.csv`

Source table for Figure 4 and Table 4.

| Column | Meaning |
|---|---|
| `station_id`, `label`, `full_label` | Project and display site labels. |
| `dem_source` | DeltaDTM GeoTIFF source or local mosaic source. This should start with `DeltaDTM`. |
| `tiles` | DeltaDTM tile filenames used in the station window. |
| `valid_fraction` | Fraction of cells in the map window with valid terrain values. |
| `median_elev_m` | Median elevation across all valid cells. This column is retained for audit only and should not be used as a main interpretive metric where DeltaDTM upper-range capping is relevant. |
| `median_lowland_elev_m` | Median elevation within the coastal-lowland mask used by the sensitivity analysis. This is the reported terrain summary. |
| `connected_0.5m_lowland_pct`, `connected_1m_lowland_pct`, `connected_2m_lowland_pct` | Fraction of coastal-lowland cells below the perturbation level and connected to boundary water/no-data. |
| `bathtub_0.5m_lowland_pct`, `bathtub_1m_lowland_pct`, `bathtub_2m_lowland_pct` | Fraction of coastal-lowland cells below the perturbation level without the ocean-connectivity filter. These columns are diagnostic contrasts only. |

## `Fig4_hypsometry_curves.csv`

Source table for Figure 5a.

| Column | Meaning |
|---|---|
| `station_id` / `label` | Site identifier and label. |
| elevation column | DeltaDTM elevation bins or sampled lowland elevations used to draw cumulative hypsometry. |
| cumulative fraction column | Cumulative fraction of coastal-lowland cells below each elevation. |

Exact column names may be regenerated by the plotting script; the publication audit should verify that the table is present and updated with the figures.

- `Table1_data_products.csv`: input product descriptions and scientific use.
- `Table2_water_level_indicators.csv`: water-level indicators derived from Figure 2 source data.
- `Table3_driver_correlations.csv`: meteorological-driver correlations derived from Figure 3 source data.
