# Submission metadata required before journal upload

The scientific analysis, figures, source-data tables and reproducibility checks can be finalized locally, but several journal-submission metadata items require author input and must not be fabricated.

## Items requiring author confirmation

| Item | Required action |
|---|---|
| Author list and affiliations | Provide the final author order, institutional affiliations and corresponding author information. |
| Author contributions | Provide contribution statements using the target journal's taxonomy, such as conceptualization, data curation, formal analysis, methodology, software, visualization, writing, review and editing. |
| Funding | Confirm whether the study had external funding. If yes, provide funder names and grant numbers. If no, use the journal's required no-funding statement. |
| Competing interests | Confirm the competing-interest statement required by the target journal. |
| Data repository DOI | Deposit processed source tables and reproducibility package in a public repository before final submission, then record the persistent identifier. |
| Code repository DOI | Archive the code or publication package in a public repository before final submission, then record the persistent identifier. |
| Ethics or permissions | Confirm that no human-subjects, animal-subjects, restricted data or permissions issues apply. |

## Core submission fields

- Abstract: use the manuscript abstract from `process_terrain_coastal_flood_CEE_manuscript.md`.
- Keywords: coastal flooding; storm surge; storm tide; DeltaDTM; GSSR; COAST-RP; ERA5; terrain sensitivity; reproducible screening.
- Corresponding author: supplied through the journal submission system and the signed author confirmation form.
- Data availability: use the final Data availability statement in the manuscript and the repository deposit checklist.

## Suggested neutral statements if applicable

These statements should be used only after author confirmation.

- Funding: "The authors received no specific funding for this work."
- Competing interests: "The authors declare no competing interests."
- Ethics: "This study used only public environmental datasets and did not involve human participants, animal subjects or restricted personal data."

## Do not infer

Do not infer author contributions, funding status, competing interests or repository DOI from the local analysis files. These are manuscript-governance metadata, not computational outputs.
